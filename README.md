## About the Project
This project is a playful website where users are asked, "Do you like me?" with two buttons: **Yes** and **No**. The twist? Every time you click "No," the "Yes" button grows larger until it takes over the entire screen, forcing you to click "Yes." Once you do, a funny GIF appears, and your name (if provided) is displayed with a personalized message.

---

## How It Started
It all began with a simple idea: **"What if I could create something fun and interactive that people could enjoy?"** I wanted to build a project that was lighthearted, engaging, and visually appealing. The concept of asking a question with a humorous twist came to mind, and thus, the "Do You Like Me?" project was born.

---

## How It Evolved
1. **Version 1**: The initial version was a basic HTML page with two buttons. Clicking "No" made the "Yes" button grow, but it was clunky and not very polished.
2. **Version 2**: I added a pop-up to ask for the user's name, improved the design with a love-themed color palette, and added a celebratory GIF when the user clicked "Yes."
3. **Version 3**: I refined the UI with pixelated fonts, 3D hover effects, and a footer. I also added a close button to the pop-up and made the "Yes" button take over the screen after 4-5 clicks.
4. **Final Version**: I added a README file (you're reading it!) and made the project more user-friendly and visually appealing.

## Features
